# Logo asset sources

These marks identify the technologies and institutions named beside them. They remain the property of their respective owners. Local copies avoid third-party requests in the visitor's browser.

## Technology marks

- **Java:** `technology/java.svg` is the official Duke Java mascot artwork (`Agent.svg`) from the [OpenJDK Duke repository](https://github.com/openjdk/duke/blob/master/vector/Agent.svg). Its view box was cropped without changing the artwork so Duke remains legible at icon size. Oracle's [Java branding guidelines](https://www.oracle.com/ae/a/ocom/docs/java-licensing-logo-guidelines-1908204.pdf) identify Duke as the open-source, BSD-licensed mark recommended for representing Java; the restricted Coffee Cup mark is deliberately not used.
- **HTML5:** `technology/html5.svg` is W3C's [HTML5 mark](https://www.w3.org/html/logo/downloads/HTML5_Logo.svg), published from the [W3C HTML5 logo page](https://www.w3.org/html/logo/) under CC BY 3.0.
- **CSS3:** `technology/css3.svg` is Devicon's [CSS3 original icon](https://github.com/devicons/devicon/blob/master/icons/css3/css3-original.svg). Devicon is a maintained, MIT-licensed development-technology icon collection. This is a representative CSS3 shield, not a W3C conformance mark.
- **JavaScript:** `technology/javascript.svg` is Devicon's [JavaScript original icon](https://github.com/devicons/devicon/blob/master/icons/javascript/javascript-original.svg). JavaScript/ECMAScript has no single maintained vendor logo; this is the established representative mark from Devicon's MIT-licensed collection.
- **Python:** `technology/python.svg` is the logo-device-only SVG from the [Python Software Foundation's official logo page](https://www.python.org/community/logos/). A view box was added without changing the artwork so the official asset scales reliably in responsive images.
- **Visual Basic:** `technology/visual-basic.svg` is Devicon's [.NET-era Visual Basic original icon](https://github.com/devicons/devicon/blob/master/icons/visualbasic/visualbasic-original.svg). It is used as a representative technology icon because Microsoft does not maintain a current standalone Visual Basic language-logo download. Devicon is MIT licensed.

Devicon licensing: [MIT license](https://github.com/devicons/devicon/blob/master/LICENSE).

## Institution mark

- **Philippine Christian University:** `pcu-logo.png` is the university seal served by the [official PCU website](https://pcu.edu.ph/) from its [original official media asset](https://pcu.edu.ph/wp-content/uploads/2022/12/cropped-cropped-PCU-logo.png). The downloaded file is a transparent 300 × 298 PNG and was not redrawn, recolored, cropped, or otherwise altered.
